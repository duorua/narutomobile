# 使用说明

本页汇总日常使用中的环境要求、注意事项和常用配置方法。遇到无法解决的问题时，请先查看[常见问题](./faq.md)。

## 软件下载

> [!TIP]
> 已经购买了 [mirror 酱](https://mirrorchyan.com/zh/get-start)服务？试试[高速下载](https://mirrorchyan.com/zh/projects?rid=MaaAutoNaruto&os=windows&arch=x64&channel=stable)！

1. 从 [Github](https://github.com/duorua/narutomobile/releases/latest) 下载软件的最新版本。

2. 将压缩文件内的**所有内容**都解压到单独的文件夹 **（必须要用单独的文件夹包着，不能和其他文件混装）**。

## 模拟器设置

1. 在模拟器设置里将调整为**锁定屏幕旋转**为横屏并设置为平板版 16:9 比例，例如 `1280×720`、`1600×900` 或 `1920×1080`，以达到最佳运行效果。
2. 不建议使用雷电模拟器；该模拟器可能出现随机点击问题。
3. 关闭模拟器的后台保活和网络桥接功能，这些功能可能导致连接异常或者点击错位。
4. 部分模拟器更新后可能自动重新开启上述功能，更新后请重新检查。

## 启动软件

1. 运行`MFAAvalonia.exe`，学习软件入门指引教程。

[软件启动相关问题](./faq.md#软件启动问题)

## 软件配置

0. 请认真阅读软件初次启动时附带的使用说明以及软件内公共。如果手滑关掉了，可以在 `设置 -> 关于我们` 中重新唤起。
1. 任务旁的齿轮表示该任务有选项或描述，请根据自己需求调整。选项旁的问号支持悬停查看说明，可以帮助理解选项作用。
2. 点击`开始任务`。

_不必过度关注实时视图的画面表现；只要任务正常运行即可。若感觉 CPU 占用率过高可以在设置中关闭实时视图。_

## 注意事项

### 游戏内注意事项

1. 使用 MAN 不需要开通游戏或 QQ 会员。如果运行过程中打开了相关界面，可能是模拟器、游戏或 MAN 的识别问题。
2. 尽量不要使用会遮挡主页功能入口的忍者站街特效，例如 `带土[十尾人柱力]`、`黑土[博人传]`。
3. 部分功能不支持周年庆等主界面特效较多的主题。
**4. 连点器默认键位对应火影训练场默认键位，与模拟器按键映射无关；如需修改，请参考下方的[自定义键位](#自定义键位)。**

### MAN 使用注意事项

1. 部分任务难以适配所有设备和社交媒体版本，例如分享类任务，可能需要手动调整选项。
2. 如果出现闪退，请参考[软件闪退](./issue.md#软件闪退)。
3. 可以重置任务、添加任务，并配合定时、通知等功能形成自己的配置。也可以创建多个配置来运行不同任务流。

### 安卓版注意事项

1. 早期开发主要面向模拟器，因此部分功能在手机上可能不可用，例如火影自动登录、切换账号和部分分享逻辑。
2. 安卓实机通常需要了解 Shizuku 的使用方法，或者取得获得 root 权限。
3. 低版本 Android 可能不支持后台模式，可以尝试使用前台模式。
4. 暂无支持鸿蒙和iOS的计划。

### PC 版注意事项

1. 右键任务可以单独运行该任务，或运行该任务及后续任务。

### 无人值守自动化

需要长时间无人值守、定时启动或自动运行时，可以使用 [AUTO-MAS](https://doc.auto-mas.top) 的 [MFA 专项](https://doc.auto-mas.top/docs/script-guide/maafw.html)。
