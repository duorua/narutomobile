# 项目结构

```bash
.agents/                      # 本地 Agent 技能配置
.codex/                       # Codex/Maa MCP 辅助配置
.github/                      # GitHub 相关配置
    ISSUE_TEMPLATE/           # Issue 模板
    workflows/                # GitHub Actions 工作流
    cliff.toml                # 变更日志生成配置
    dependabot.yml            # Dependabot 配置
.vscode/                      # VSCode 编辑器配置
    extensions.json           # 推荐扩展列表
    settings.json             # 项目设置
    tasks.json                # 编辑器任务配置
Android/                      # Android 客户端
    MaaFwApp/                 # Android 外壳 Git 子模块
    profile.yaml              # Android 构建配置
    README.md                 # Android 客户端构建说明
agent/                        # Agent Server 模块代码
    custom/                   # 自定义识别和动作
        action/               # 自定义动作实现
        reco/                 # 自定义识别实现
        sink.py               # 任务事件检查（如分辨率校验）
        utils.py              # 自定义模块工具函数
    utils/                    # Agent 通用工具函数
    main.py                   # Agent Server 主入口
assets/                       # MaaFramework 项目资源
    android/                  # Android 打包使用的 interface 基版
        interface.json
    resource/                 # 官服资源包
        announcement/         # 首页公告、协议与配图
        base/                 # image、model、pipeline 等基础资源
    tasks/                    # Pipeline 任务文件
        preset/               # 可复用任务片段
    interface.json            # Project Interface V2 主配置
deps/                         # 本地依赖与校验辅助文件
    tools/                    # MaaFramework Interface、Pipeline 和 Custom JSON Schema
docs/                         # 文档目录
    develop/                  # 开发相关文档
    guide/                    # 中文说明文档
    imgs/                     # 图片资源
    .markdownlint.yaml        # Markdown 完整检查配置
    README.md                 # 文档编辑说明
tools/                        # 构建与维护脚本
    assetes/                  # 素材图片（目录名保留历史拼写）
    ci/                       # CI 安装、下载和资源检查脚本
    build_android_apk.py      # Android APK 辅助构建
    configure_android_app_identity.py
                              # 配置 Android 应用标识
    deploy_python_env_linux.sh
                              # Linux Python 环境部署
    download_maafw.py         # 下载 MaaFramework
    get_cli.bat               # Windows 获取 CLI
    get_cli.sh                # Unix 获取 CLI
    install_dev.py            # 开发/运行环境安装
    prepare_android_pi.py     # 准备 Android Project Interface
    setup.bat                 # Windows 一键配置
    setup_full_python.py      # 下载并解压 Python
    utils.py                  # 工具函数
.editorconfig                 # 编辑器格式配置
.gitattributes                # Git 属性配置
.gitignore                    # Git 忽略文件配置
.gitmodules                   # Git 子模块配置
.markdownlint.yaml            # 根目录 Markdown 简化检查配置
.pre-commit-config.yaml       # 预提交钩子配置
.prettierignore               # Prettier 忽略配置
.prettierrc.mjs               # 代码格式化配置
.python-version               # Python 版本锁定
CONTACT                       # 联系方式
CONTRIBUTING.md               # 贡献与授权说明
Custom_Keybindings.json       # 自定义技能键位配置
DISCLAIMER.md                 # 免责声明
LICENSE                       # 许可证文件
MaaDebugger.bat               # 启动 MaaDebugger
README.md                     # 中文说明文档
README_EN.md                  # 英文说明文档
change_Keybindings.py         # 技能键位替换工具
default_Keybindings.json      # 默认技能键位配置
maatools.config.mts           # maa-tools 配置
package.json                  # Node.js 开发脚本和依赖
pnpm-lock.yaml                # pnpm 依赖锁定文件
pyproject.toml                # Python 项目、工具链和测试配置
requirements.txt              # 运行时 Python 依赖列表
uv.lock                       # uv 依赖锁定文件
自定义键位.bat                 # 启动技能键位替换工具
```

> 本地生成的 `.venv/`、`node_modules/`、`debug/`、`install/`、`Android/pi-root/`、`Android/agent-dist/` 等目录不列入源码结构。
